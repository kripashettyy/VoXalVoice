# Background Music Assets

Place CC0-licensed MP3 files here. Each filename must match a key in `BUILTIN_TRACKS` inside `reels_processor.py`.

Expected files:
- `lofi.mp3`
- `cinematic.mp3`
- `upbeat.mp3`
- `calm.mp3`

Free CC0 sources:
- https://pixabay.com/music/
- https://mixkit.co/free-music/
- https://freemusicarchive.org

Keep files under 5 MB each (30–60 second loops work best).
